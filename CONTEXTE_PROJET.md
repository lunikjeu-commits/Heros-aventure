# CONTEXTE PROJET — LC STUDIO (jeu d'action 2D sombre)
Techno : HTML5 Canvas + JS modules, déployé sur GitHub Pages.
## Journal de bord
- Étape 1 : splash LC STUDIO + sélection de 5 héros (3 ouverts, ange et barbare verrouillés).
- Étape 2 : moteur de combat (js/combat/*), contrôles tactiles, ennemis, boss, effets.
- Étape 3 : équipement (js/gear/*, js/save.js, gear.css) : 6 emplacements, 4 raretés, amélioration, évolution, recyclage, butin.
- Étape 4 : compagnons (js/companions/*, js/combat/companion.js, comp.css) : Braise (feu), Givre (glace), Orage (foudre).
- Fichiers étape 4 : comp.css, js/companions/{data,logic,art,screen}.js, js/combat/companion.js, js/save.js (modifié), js/menu.js (modifié), js/combat/engine.js (modifié)
- Règles : éveil payant (250/600/1000 or), niveau max 15, 1 compagnon actif, attaque seul + bonus passif (attaque, défense, critique).
- État : compagnons jouables en combat, sauvegardés.
- Prochaine action : carte des mondes (20 niveaux, boss tous les 5) + déblocage Ange/Barbare.
